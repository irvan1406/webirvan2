Kantor ini memakai token GitHub yang sama seperti panel admin web ini — tidak perlu buat token baru. Di browser yang sama dengan panel admin, token terbaca otomatis. Di aplikasi, tempel sekali (salin dari kolom token panel admin — kolomnya sudah terisi), sesudah itu tersimpan.

Syaratnya: token memuat repo vanx-database (Contents: Read and write). Kalau belum, tambahkan di GitHub → Settings → Developer settings → Personal access tokens → token kamu → Repository access. Nilai token tidak berubah.

🖥️ Adegan 3D tidak bisa dimuat di perangkat ini.
Menu perintah di bawah tetap berfungsi penuh.

Perintah kelompok (tombol cepat di atas, atau tulis sendiri dengan kata "semuanya ...") langsung digerakkan figurnya di kantor dalam beberapa detik — tidak menunggu antrean biasa.

Perintah masuk antrean kantor. Halaman ini memeriksa antrean tiap ±5 detik — figur agen langsung bereaksi, menghampiri titik bos dulu untuk melapor, lalu ke meja. VanX mengambil & mengerjakannya beneran (±5 menit sekali); hasilnya muncul di Papan Perintah. Saat waktu sholat, perintah untuk VanX & Agen Muse menunggu sampai sholat selesai.
