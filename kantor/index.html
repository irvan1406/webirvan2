Kantor ini memakai token GitHub yang sama seperti panel admin web ini — tidak perlu buat token baru. Di browser yang sama dengan panel admin, token terbaca otomatis. Di aplikasi, tempel sekali (salin dari kolom token panel admin — kolomnya sudah terisi), sesudah itu tersimpan.

Syaratnya: token memuat repo vanx-database (Contents: Read and write). Kalau belum, tambahkan di GitHub → Settings → Developer settings → Personal access tokens → token kamu → Repository access. Nilai token tidak berubah.

🖥️ Adegan 3D tidak bisa dimuat di perangkat ini.
Panel perintah di bawah tetap berfungsi penuh.

Seret untuk memutar, cubit/gulir untuk zoom. Kantor utama terhubung ke Ruang API (barat) dan Musola + tempat wudu (timur). Etalase Proyek di dinding timur kantor utama. Pekerjaan asli hanya dari perintah — sisanya suasana.

Perintah masuk antrean kantor. VanX mengambilnya ±5 menit sekali, agennya berjalan ke meja dan mengerjakan beneran; hasilnya muncul di Papan Perintah. Saat waktu sholat, perintah untuk VanX & Agen Muse menunggu sampai sholat selesai.
