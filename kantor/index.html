🔑 Kunci Kantor

Halaman ini memakai token GitHub yang sama seperti panel admin web ini — tidak perlu buat token baru. Kalau kamu membuka halaman ini di browser yang sama dengan panel admin, tokennya terbaca otomatis. Di dalam aplikasi, tempel sekali saja (salin dari kolom token di panel admin web — kolomnya sudah terisi) lalu tersimpan seterusnya.

Syaratnya cuma satu: token itu harus memuat repo vanx-database (akses Contents: Read and write). Kalau belum, tambahkan lewat GitHub → Settings → Developer settings → Personal access tokens → token kamu → Repository access → tambahkan vanx-database. Nilai tokennya tidak berubah.

📨 Kirim Perintah

Perintah masuk antrean yang sama dengan Kantor 3D. VanX mengambilnya ±5 menit sekali, mengerjakannya beneran, dan hasilnya muncul di papan bawah ini. Saat waktu sholat, perintah untuk VanX & Agen Muse menunggu sampai sholat selesai.
