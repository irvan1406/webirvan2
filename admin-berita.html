Token GitHub

Token adalah kuncinya. Tempel token GitHub (PAT) dengan akses Contents: Read and write ke repo irvan1406/webirvan2. Token hanya tersimpan di browser ini dan tidak pernah ada di dalam file situs. Tanpa token, form di halaman ini terkunci untuk penerbitan.

Kelola Berita

Daftar di bawah dimuat dari berita.json yang sedang tayang. Urutan tampilan di portal mengikuti urutan daftar ini (terbaru menurut tanggal ditampilkan lebih dulu). Gunakan tombol Naik/Turun untuk mengubah urutan, Edit untuk mengubah isi, Duplikat untuk menyalin, dan Hapus untuk menghapus.
