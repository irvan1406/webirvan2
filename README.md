# irvanmaulana.my.id

Website etalase proyek Irvan Maulana: **VanNota**, **MyDevice**, dan
**Bot Nasabah** — beserta paket unduhan kode sumbernya di folder `unduhan/`.

Semua paket unduhan sudah dibersihkan dari token, ID, dan data pribadi pemilik:

- `unduhan/vannota.zip` — aplikasi web struk thermal ESC/POS + QR Wi-Fi
  (+ pembungkus Android).
- `unduhan/mydevice.zip` — proyek Android MyDevice; token bot & ID Telegram
  sudah diganti placeholder, wajib diisi milik sendiri (lihat
  `PANDUAN-ISI-TOKEN.md` di dalam paket).
- `unduhan/bot-nasabah.zip` — bot WhatsApp Bot Nasabah (Baileys/Node.js);
  `.env` asli tidak disertakan, gunakan `.env.example` di dalam paket.

Situs ini adalah GitHub Pages dari repo ini dengan domain kustom
`irvanmaulana.my.id` (lihat berkas `CNAME`).
