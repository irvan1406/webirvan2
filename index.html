Khusus MyDevice — baca sebelum memakai. Paket unduhan MyDevice sudah dikosongkan dari token bot & ID Telegram pemilik aslinya. Tentang pembuatnya

Saya Irvan Maulana, tinggal di Kalibaru, Banyuwangi. Saya membangun alat-alat ini awalnya untuk kebutuhan sendiri dan pekerjaan sehari-hari — struk untuk usaha, bot untuk mengelola nasabah, dan aplikasi untuk menjaga HP — lalu saya rapikan supaya bisa dipakai orang lain juga.

Semua proyek di halaman ini saya bagikan gratis dan apa adanya. Silakan unduh, pelajari, dan modifikasi untuk kebutuhanmu. Kalau menemukan bug atau punya saran fitur, itu sangat membantu pengembangan berikutnya.

01Dibuat karena butuh. Setiap fitur lahir dari masalah nyata, bukan asal bikin.
02Aman dibagikan. Paket unduhan tidak memuat token, kata sandi, atau data pribadi siapa pun.
03Terus dirawat. Bot Nasabah saja sudah melewati puluhan revisi dan ratusan kali uji langsung.
