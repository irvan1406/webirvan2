Cara kerja panel ini

Singkatnya: edit di sini → klik Simpan & Terbitkan → situs publik berubah (±1 menit).

  1. Semua isi situs (proyek, kalimat, unduhan) tersimpan di satu berkas data.json di repositori GitHub situsmu.
  2. Panel ini membaca & menulis berkas itu lewat API GitHub memakai token akses milikmu (atur di tab 🔑 Koneksi & Keamanan).
  3. Proyek yang saklarnya mati tidak muncul di situs publik. Foto/video yang diunggah tersimpan di folder img/ repo.
  4. Perubahan teks/proyek belum berlaku sebelum kamu menekan Simpan & Terbitkan (unggahan foto/berkas berlaku seketika).

Koneksi GitHub

Panel menyimpan perubahan dengan menulis ke repositori situs lewat API GitHub. Token hanya tersimpan di browser ini (tidak pernah masuk ke berkas situs) dan hanya dikirim ke api.github.com.

Cara membuat token ada di tab ❓ Bantuan. Izin yang dibutuhkan hanya Contents: Read & Write untuk repo situs ini.

Kata Sandi Panel (Kunci Layar)

Sandi ini hanya mengunci tampilan panel di browser ini — bukan pengaman sesungguhnya (pengaman sesungguhnya adalah token GitHub di atas: tanpa token, tidak ada yang bisa mengubah situs). Panel sudah memiliki sandi bawaan dari pemilik; ganti lewat formulir ini bila perlu. Mengosongkan kedua kotak lalu menyimpan akan mematikan kunci layar.

Membuat Token GitHub (sekali saja)

  1. Buka GitHub → foto profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nama bebas (mis. “Admin Situs”), masa berlaku sesuai keinginanmu.
  3. Repository access: pilih Only select repositories → centang repo situs ini (webirvan2).
  4. Permissions → Repository permissions → Contents: pilih Read and write. (Lainnya biarkan.)
  5. Klik Generate token, salin tokennya, tempel di tab 🔑 Koneksi & Keamanan, lalu klik Hubungkan & Muat Data.

Alternatif: token klasik (classic) dengan centang repo juga bisa, tapi token fine-grained di atas jauh lebih aman karena hanya bisa menyentuh satu repo ini.

Tanya–Jawab

Kenapa perubahan saya belum muncul di situs?
Setelah Simpan & Terbitkan, GitHub Pages butuh ±30–60 detik membangun ulang. Segarkan halaman situs (kadang perlu hard-refresh).

Bagaimana menambah video ke proyek?
Buka tab Proyek → Sunting → isi kolom “Tautan video” dengan tautan YouTube (watch/shorts) atau tautan berkas .mp4. Video muncul paling depan di jendela detail proyek.

Bagaimana proyek yang hanya aplikasi (tanpa situs)?
Di editor proyek: kosongkan “Tautan Kunjungi”, isi “Tautan Unduh” dengan alamat berkas (mis. unduhan/aplikasiku.apk — berkasnya diunggah lewat tab Unduhan atau editor baris unduhan). Kartu proyek otomatis menampilkan tombol “⬇ Unduh Aplikasi”.

Ukuran berkas maksimum?
API GitHub nyaman sampai ±25 MB per berkas. Foto preview idealnya di bawah 1 MB (JPG hasil tangkapan layar sudah cukup).

Apakah halaman admin ini rahasia?
Siapa pun bisa membuka tampilannya, tapi tanpa token GitHub milikmu mereka tidak bisa memuat-ubah apa pun yang berarti (data situs memang publik) dan mutlak tidak bisa menyimpan perubahan. Jangan sebarkan tokenmu ke siapa pun.
