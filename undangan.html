🌐 Alamat & Custom Domain

Alamat utama (selalu aktif):

—

Kalau pembeli pakai custom domain sendiri:

Contoh: https://weddingku.com/?to=Keluarga+Besar+Hartono
  1. Pembeli membeli domain sendiri, misalnya weddingku.com, di penyedia domain mana pun.
  2. Isi domain itu di Langkah 3 → Domain & Alamat Undangan. Tautan per tamu otomatis menjadi weddingku.com/?to=Nama+Tamu.
  3. Opsi lanjutan — DNS: mengarahkan CNAME/A record domain pembeli ke hosting penjual hanya bekerja bila hosting tujuan memang dikonfigurasi untuk menerima domain kustom tersebut; mengarahkan DNS saja tidak otomatis menampilkan undangan. Karena itu jalur yang dijamin bekerja adalah Paket HTML Mandiri di hosting domain pembeli sendiri (langkah berikutnya).
  4. Alamat utama di irvanmaulana.my.id/Undangan.html tetap jadi cadangan — kalau custom domain belum aktif, tamu tetap bisa membuka alamat utama.
  5. Cara utama — Paket HTML Mandiri: unduh satu file HTML di bawah ini, lalu letakkan file itu sebagai halaman utama (index) di hosting domain pembeli. File itu sudah berisi seluruh data undangan ini — tamu membuka weddingku.com/?to=Nama+Tamu dan nama tamunya tampil di sampul. Tidak perlu memaksakan format /nama-tamu.

Isi Paket HTML Mandiri dibuat dari data undangan saat ini. Kalau data diubah, unduh ulang paketnya lalu ganti file di hosting domain pembeli — atau cukup pakai tautan edit di bawah untuk mengedit versi di domain utama.

Ganti nama tamunya, klik Buat Tautan Tamu, lalu kirim tautan itu ke tamu tersebut. Nama tamu otomatis tampil di sampul “Kepada Yth”.

✏️ Pembeli Bisa Edit Sendiri Setelah Membeli

Serahkan Kode Undangan dan Tautan Edit di bawah ini kepada pembeli saat serah-terima. Dengan keduanya, pembeli bisa mengubah nama, tanggal, tempat, foto tema / template, dan data lain sendiri, kapan saja, tanpa harus menghubungi penjual:

  1. Buka irvanmaulana.my.id/Undangan.html (atau custom domain pembeli).
  2. Tempel Kode Undangan di kolom “Buka undangan dari kode” di bawah, atau buka langsung Tautan Edit-nya.
  3. Ubah data / ganti template, lalu salin Kode & Tautan Undangan yang baru — bagikan ulang tautan baru ke tamu.
—

Simpan kode & tautan edit baik-baik dan jangan bagikan ke tamu — siapa pun yang memegangnya bisa mengedit undangan. Tautan untuk tamu adalah tautan undangan biasa, bukan tautan edit.

Kode undangan berisi seluruh data + desain + domain. Tamu membuka tautan undangan (#u=KODE), sedangkan pembeli membuka tautan edit (#edit=KODE) untuk masuk kembali ke mode edit dengan data yang sama.

Pertanyaan umum

Yang paling sering ditanyakan calon pembeli undangan digital.

Apakah tamu harus install aplikasi?

Tidak. Tamu cukup membuka tautan undangan dari WhatsApp dan undangan tampil penuh di browser HP mereka.

RSVP tamu masuk ke mana?

Formulir RSVP & ucapan di undangan membuka WhatsApp tamu dengan pesan yang sudah terisi, terkirim ke nomor mempelai yang kamu isi di Langkah 3.

Bisakah nama tamu berbeda-beda di sampul?

Bisa. Nama tamu tampil di bagian “Kepada Yth” pada sampul. Saat membuat pesan untuk tamu lain, ganti nama tamunya lalu salin lagi pesannya.

Bagaimana cara mengedit undangan yang sudah jadi?

Simpan kode undangan dari Langkah 4. Buka irvanmaulana.my.id/Undangan.html, tempel kode itu di kolom “Buka undangan dari kode”, atau buka langsung Tautan Edit (#edit=KODE) yang diberikan saat pembelian — semua data & desainnya termuat kembali dan bisa diubah sendiri oleh pembeli.

Undangan ini tampil di alamat apa?

Alamat utamanya irvanmaulana.my.id/Undangan.html. Setiap undangan punya tautan sendiri berisi kodenya, jadi satu halaman itu bisa menampilkan banyak undangan berbeda sesuai tautan yang dibuka tamu.

Bisakah memakai custom domain yang sudah saya beli, misalnya weddingku.com?

Bisa, dengan cara utama: isi domainmu di Langkah 3, lalu unduh Paket HTML Mandiri di Langkah 4 dan letakkan file itu di hosting domainmu sendiri. Tautan tamu menjadi weddingku.com/?to=Nama+Tamu — nama tamu otomatis tampil di sampul. Opsi mengarahkan DNS ke hosting penjual hanya bekerja bila hosting itu memang dikonfigurasi menerima domainmu, jadi bukan jalur utama. Harga domain dibeli & diperpanjang oleh pemilik domain di penyedia domainnya masing-masing, dan alamat utama tetap bisa dipakai sebagai cadangan.

Setelah membeli, apakah saya masih bisa mengedit sendiri?

Ya. Saat serah-terima kamu menerima Kode Undangan + Tautan Edit. Simpan keduanya baik-baik (jangan dibagikan ke tamu), dan kamu bisa mengubah nama, tanggal, tempat, maupun template kapan saja lalu membagikan tautan undangan yang baru.
